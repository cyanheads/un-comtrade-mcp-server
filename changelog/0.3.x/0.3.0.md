# 0.3.0 — 2026-11-03

## Added

- Publish the un-comtrade-guide skill through MCP resources and package/plugin delivery.
- **Quantity metadata** includes quantity and alternate-quantity units plus quantity/weight estimation flags, preserving unknown units and absent values. ([#28](https://github.com/cyanheads/un-comtrade-mcp-server/issues/28))
- **Bilateral balances** accept `partner_code` and identify the partner while retaining the reporter's perspective. ([#29](https://github.com/cyanheads/un-comtrade-mcp-server/issues/29))
- **Reporter selection** accepts deduplicated reporter arrays or omission with an explicit partner; unserved reporters are disclosed. ([#30](https://github.com/cyanheads/un-comtrade-mcp-server/issues/30))

## Changed

- **Keyless HS editions** reject explicit H0–H6 trade queries, including otherwise successful empty queries. Use `HS` for as-reported data, not conversion to a selected edition, or configure `COMTRADE_SUBSCRIPTION_KEY`. ([#20](https://github.com/cyanheads/un-comtrade-mcp-server/issues/20))
- **Commodity rankings** retrieve the reported edition's complete category set and use matching TOTAL for shares; `rank` is optional when coverage or values are unknown. Coverage metadata identifies incomplete retrieval and unresolved codes. ([#25](https://github.com/cyanheads/un-comtrade-mcp-server/issues/25))
- **Availability browsing** returns stable limit/offset pages with matching totals and continuation metadata. Paging still fetches the matching upstream list. ([#26](https://github.com/cyanheads/un-comtrade-mcp-server/issues/26))
- **Packaging and development tooling** add Agent Plugins metadata, validate published skills, strip build-only dependency files from MCPB bundles, and sync framework skills and checks.

## Fixed

- **Ranking periods** infer annual or monthly frequency from calendar-valid input. ([#21](https://github.com/cyanheads/un-comtrade-mcp-server/issues/21))
- **Country resolution** preserves ISO-2 and prioritizes exact identities and valid reporters, including USA reporter 842. ([#22](https://github.com/cyanheads/un-comtrade-mcp-server/issues/22))
- **Services trade** uses combined EB data and categories, exposes row classification, and corrects annual-period and credit/debit guidance. Availability retains its independent EB10 default. ([#23](https://github.com/cyanheads/un-comtrade-mcp-server/issues/23))
- **Historical commodities** search the selected HS/SITC catalog and enrich rows from their actual edition; reference failures retain codes and values with a notice. ([#24](https://github.com/cyanheads/un-comtrade-mcp-server/issues/24))
- **Input validation** normalizes supported casing and whitespace, validates period/frequency agreement and code grammar, and relays recognized upstream validation details safely. Retains HS `9999AA`, SITC trailing-X memorandum codes, and open availability identifiers including B4/B5. ([#27](https://github.com/cyanheads/un-comtrade-mcp-server/issues/27))
- **Goods totals** exclude overlapping transport/customs/secondary-partner breakdowns for explicit partners before balance arithmetic. ([#29](https://github.com/cyanheads/un-comtrade-mcp-server/issues/29))
