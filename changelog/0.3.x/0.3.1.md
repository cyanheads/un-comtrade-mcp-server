# 0.3.1 — 2026-11-05

## Added

- **Services `classification`** on `comtrade_get_services_trade` selects EB as reported (default) or UN Comtrade's converted `EB10`/`EB02` series; rows carry `isOriginalClassification`, and `EB10S` is rejected with a message pointing to `EB`. ([#34](https://github.com/cyanheads/un-comtrade-mcp-server/issues/34))
- **Category `schemes` and `ebParent`** on `comtrade_list_service_categories` name the EBOPS scheme catalogs listing each code; EB10's top level lists under `parent_code: "200"`. ([#34](https://github.com/cyanheads/un-comtrade-mcp-server/issues/34))
- **`offset`/`nextOffset`** on `comtrade_search_commodities` and `comtrade_list_service_categories` page through matches. ([#37](https://github.com/cyanheads/un-comtrade-mcp-server/issues/37))
- **`reportersWithoutRecords`** on `comtrade_get_trade_flows` lists served reporters that returned no rows. ([#35](https://github.com/cyanheads/un-comtrade-mcp-server/issues/35))
- **`entryEffectiveDate`/`entryExpiredDate`** on `comtrade_lookup_countries` matches and `comtrade://countries`. ([#35](https://github.com/cyanheads/un-comtrade-mcp-server/issues/35))
- **`classification`** on `comtrade_get_top_partners` accepts HS editions and SITC, is echoed in the result, and rejects a SITC code under an HS classification with a message naming it. ([#38](https://github.com/cyanheads/un-comtrade-mcp-server/issues/38))

## Changed

- **Keyless pacing** starts preview requests at least 4 s apart and serves 8 periods per flows or services call and 4 per balance call (12 with a subscription key). Periods that fail or miss the single 52 s call budget are listed in `unservedPeriods` with a notice, and rankings share one deadline; a call where every period fails returns `rate_limited` or `deadline_exceeded`. ([#33](https://github.com/cyanheads/un-comtrade-mcp-server/issues/33))
- **Partner-only reporter codes** (0 World, 250 Metropolitan France) with no data get a notice naming the reporter-valid code (250 → 251) on every trade tool, and `comtrade_get_trade_balance` fails with `partner_only_reporter` instead of `no_data`. An empty ranking names the reporter from reference data. ([#35](https://github.com/cyanheads/un-comtrade-mcp-server/issues/35))
- **Country lookup** pulls in entries sharing an ISO-3 identity and orders exact ISO match, reporter-valid, current before expired, name, then code; `role: "partner"` returns only partner-area entries. ([#35](https://github.com/cyanheads/un-comtrade-mcp-server/issues/35))
- **`limit`** is honored exactly on commodity search, service categories, top partners, and top commodities; the former return-everything thresholds are gone. ([#37](https://github.com/cyanheads/un-comtrade-mcp-server/issues/37))
- **`freq`** is optional on flows, balance, and availability and is inferred from the period length; mixed lengths and a disagreeing explicit value are still rejected. ([#38](https://github.com/cyanheads/un-comtrade-mcp-server/issues/38))
- **Input handling** accepts any casing of `classification` on commodity search, rejects `comtrade_get_top_commodities` reporter and partner codes outside 0–999, and relays one period per upstream validation detail. ([#38](https://github.com/cyanheads/un-comtrade-mcp-server/issues/38))
- **Services empty results** name the code's EBOPS scheme and suggest the converted series when one applies. ([#34](https://github.com/cyanheads/un-comtrade-mcp-server/issues/34))

## Fixed

- **Startup** no longer fails when UN republishes a reference file with a partner-shaped row: country identity comes from `id`/`text` with ISO codes in either spelling, bad rows are dropped and logged, and startup fails only on an empty catalog or fewer than half valid rows. ([#32](https://github.com/cyanheads/un-comtrade-mcp-server/issues/32))
- **Zero placeholders** for `qty`/`altQty` (unit code −1) and for `netWgt`/`grossWgt`/`cifvalue`/`fobvalue` beside a positive value are omitted instead of reported as measurements. ([#36](https://github.com/cyanheads/un-comtrade-mcp-server/issues/36))
- **HS `TOTAL`** keeps level 0 and no longer appears in `aggr_level` filters or `comtrade://hs-classification/{2|4|6}`. ([#39](https://github.com/cyanheads/un-comtrade-mcp-server/issues/39))
- **EB scheme catalogs** that load empty count as unavailable (untagged rows plus a notice, not cached), and `parent_code` matches lowercase EB ids such as `3a.3`. ([#34](https://github.com/cyanheads/un-comtrade-mcp-server/issues/34))
- **Balance errors** where some periods answered empty while others failed open with the served periods that returned no trade data. ([#33](https://github.com/cyanheads/un-comtrade-mcp-server/issues/33))

## Dependencies
