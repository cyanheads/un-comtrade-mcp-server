# 0.3.2 — 2026-11-11

## Added

- **`residual`** on `comtrade_get_top_commodities` rows marks the not-specified code (99 for chapters, 9999 for headings); the row stays ranked, and a notice explains it when it is on the page. ([#48](https://github.com/cyanheads/un-comtrade-mcp-server/issues/48))
- **`note`** on `comtrade_lookup_countries` matches carries the catalog's long-form name or coverage note. ([#45](https://github.com/cyanheads/un-comtrade-mcp-server/issues/45))
- **`suggestedPartnerCode`** on `partner_only_reporter` and `no_data` errors names the code to query instead. ([#44](https://github.com/cyanheads/un-comtrade-mcp-server/issues/44))

## Changed

- **`upstream_unavailable`** is the reason for a period whose UN Comtrade request ends in a 5xx or network failure after retries: the period is listed in `unservedPeriods` with its HTTP status and the other periods are kept; when every period fails the call fails with it, ranked below `rate_limited` and above `deadline_exceeded`. A `Retry-After` over 60 s reaches the caller as `retryAfter` with a "Wait N seconds" hint, and `comtrade_get_trade_balance` ranks both flows' failures together. ([#40](https://github.com/cyanheads/un-comtrade-mcp-server/issues/40))
- **Partner-only codes** map to their reporter-valid counterpart (158 → 490) in lookups and in empty-result notices for `partner_code` as well as `reporter_code`. ([#44](https://github.com/cyanheads/un-comtrade-mcp-server/issues/44))
- **Country lookup** matches common names ("UK", "Turkey"), official names, and accent-free spelling, ranks exact matches before partial ones, and trims the catalog; `include_groups: false` says so when only groupings matched. ([#45](https://github.com/cyanheads/un-comtrade-mcp-server/issues/45), [#44](https://github.com/cyanheads/un-comtrade-mcp-server/issues/44))
- **Commodity and service-category search** accepts dotted HS codes (`0901.11`) and ranks exact code, code prefix, whole-word description, then other matches. ([#47](https://github.com/cyanheads/un-comtrade-mcp-server/issues/47))
- **`cmd_code` and `period`** inputs are deduplicated before the per-call caps apply on flows, services, and balance.
- **Framework** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22 with the synced skills, scripts, and agent docs.

## Fixed

- **`comtrade_get_trade_balance`** rejects overlapping `cmd_code` entries (a code beside its sub-code, `TOTAL` beside another entry, `AG<n>` beside another selector or a code of another length) with `overlapping_cmd_codes` instead of counting the shared trade twice. ([#42](https://github.com/cyanheads/un-comtrade-mcp-server/issues/42))
- **Balance and coverage ratio** are reported only when both flows have data, with a note when neither does; the ratio renders at full precision and a zero balance carries no surplus or deficit label. ([#43](https://github.com/cyanheads/un-comtrade-mcp-server/issues/43))
- **Blank queries** are rejected by `comtrade_lookup_countries` and `comtrade_search_commodities` instead of returning the whole catalog, as is a commodity query with no letter or digit; a country query of only combining marks matches nothing, and "no match" notices escape the echoed query. ([#46](https://github.com/cyanheads/un-comtrade-mcp-server/issues/46))
- **`comtrade://hs-classification`** list entries carry their `title` again.
