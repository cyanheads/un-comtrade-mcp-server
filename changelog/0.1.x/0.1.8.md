# 0.1.8 — 2026-10-07

## Changed

- **MCP input repair** accepts safe integers for string fields through mcp-ts-core 0.13.9; invalid arguments receive field-specific recovery hints.
- **Error envelopes** gain request IDs and automatic declared recovery hints from 0.13.10, framework-generated IDs from 0.13.12, and omit framework-generated `data.rootCause` from 0.13.13.
- **Docker** uses Bun 1.4.2 build/dependency stages and a slim runtime, cross-installs production dependencies, installs OTel peers through supply-chain guards, and prunes musl-only bindings.
- **Packaging** excludes MCPB archives from npm and scratch, cache, logs and idea documents from bundles; ignore rules cover env files and registry credentials.
- **Development tooling** refreshes framework scripts and skills, CodeQL language categories, and configuration, logging, telemetry and error-contract guidance.
- **Regression coverage** checks startup rejection, session defaults and overrides, and country lookup success, empty results and invalid input.

## Fixed

- **Startup configuration** validates Comtrade settings before fetching reference data, so invalid configuration fails immediately with the named environment variable.
- **Registry launch metadata** uses `npx` without `run start:*` arguments and explicitly selects HTTP for the streamable transport entry.
