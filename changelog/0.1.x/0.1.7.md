# 0.1.7 — 2026-09-20

## Changed

- **`MCP_SESSION_MODE` defaults to `stateless`, declared in `src/index.ts`** ([#12](https://github.com/cyanheads/un-comtrade-mcp-server/issues/12)) — no tool calls `ctx.requestInput`, so `createApp({ sessionMode: 'stateless' })` states the posture in code instead of leaving it to `MCP_SESSION_MODE`, which previously defaulted to `auto` → `stateful` when unset. `.env.example` now sets it uncommented.
- **A rejected tool call classifies as `InvalidParams` (-32602) with `data.reason: "invalid_arguments"` and a synthesized recovery hint** on every transport, in place of the prior generic `ValidationError` — an unknown key, wrong type, or missing field now returns the same structured `error.data` a client actually receives.
- **A caller disconnect classifies as `RequestCancelled` (-32011)** instead of a generic internal error, and an upstream 500 from the Comtrade API now retries as transient instead of failing on the first attempt.
- **HTTP transport**: a cancelled request's SSE stream closes immediately instead of waiting for keep-alive, and `SIGTERM`/`SIGINT` now exit the process explicitly within a 10s ceiling instead of waiting on the event loop to drain.
- **Unreachable `errors[]` entries dropped from seven tools** (`comtrade_get_data_availability`, `comtrade_get_services_trade`, `comtrade_get_top_commodities`, `comtrade_get_top_partners`, `comtrade_get_trade_flows`, `comtrade_lookup_countries`, `comtrade_search_commodities`) — these return an empty result with an `enrich.notice()` on "no match" rather than throwing, so the declared `no_data`/`no_match`/`api_error` contracts were never reachable. `comtrade_get_trade_balance`'s real `no_data` throw now forwards `ctx.recoveryFor('no_data')`.
- **`COMTRADE_SUBSCRIPTION_KEY` is wired through `userConfig` on both plugin manifests** — `.claude-plugin/plugin.json` previously declared no `userConfig` at all, and `manifest.json`'s entry lacked the `default: ""` the framework's packaging lint now requires; a Claude Desktop or Codex install can now actually set the key.
- **Skill tree moves from `skills/` to `framework-skills/`** — a server shipping `.claude-plugin/`/`.codex-plugin/` no longer hands its development skills to every installing agent. `AGENTS.md` joins `CLAUDE.md` as a mirrored doctrine copy for non-Claude harnesses.
