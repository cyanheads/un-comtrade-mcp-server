# 0.1.5 — 2026-06-12

## Added

- **`truncated`** boolean output field on `comtrade_search_commodities` and `comtrade_list_service_categories` — `true` when results are capped at the limit (`totalMatches` exceeds `shown`). Surfaced in `format()` as `**Truncated:** yes/no`.

## Changed

- **`createApp()`** now sets `name` and `title` to `un-comtrade-mcp-server` explicitly so every client surface shows the hyphenated server identity rather than the npm-scoped package name.
- **`bundle`** script runs `scripts/clean-mcpb.ts` after `mcpb pack` to prune dependency-shipped agent docs (`skills/`, `.claude/`, `.agents/`) nested under `node_modules/` that root-anchored `.mcpbignore` patterns cannot reach.
- **`Dockerfile`** declares `ARG APP_VERSION` with a matching `org.opencontainers.image.version` label and adds a bun-native `HEALTHCHECK` against `/healthz`.
- **`.mcpbignore`** patterns are root-anchored (`/`-prefixed) and now exclude `/.agents/` and `/skills/`.
- **`manifest.json`** drops the redundant `repository` field.
- Vendored skills and devcheck scripts synced to the framework `^0.10.6` release.
