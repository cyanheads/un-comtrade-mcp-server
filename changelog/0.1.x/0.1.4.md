# 0.1.4 — 2026-06-10

## Fixed

- **Trade totals** (`partnerCode=0`) now read the API's single aggregate row (`motCode=0` / `customsCode=C00` / `partner2Code=0`) instead of summing all dimension-expanded breakdown rows. Germany 2022 exports: was ~$13.57T (sum of 90 rows), now $1.696T matching the API aggregate. ([#4](https://github.com/cyanheads/un-comtrade-mcp-server/issues/4))
- **Partner rankings** deduplicate by partner (max-value row per `partnerCode`) so each partner appears at most once. Commodity-breakdown queries (`aggrLevel` set or multi-code `cmdCode`) are exempt so per-commodity rows survive. Poland 2022: appeared at ranks 2 and 3 before fix, now appears exactly once at rank 2. ([#5](https://github.com/cyanheads/un-comtrade-mcp-server/issues/5))
- **Services descriptions** resolve via the EBOPS reference instead of HS. `cmdCode=3` now returns `Transport`, not `Cereals`; `cmdCode=10` returns `Other business services`. ([#6](https://github.com/cyanheads/un-comtrade-mcp-server/issues/6))
- **`RawTradeRow`** now declares `motCode`, `customsCode`, `partner2Code`, and `isAggregate` fields explicitly for type-safe aggregate filtering.

## Changed

- **`COMTRADE_SUBSCRIPTION_KEY`** added to `server.json` stdio `environmentVariables[]` to align with the `manifest.json` `user_config` entry (packaging lint gate).
- **`CITATION.cff`** added; `manifest.json`, `README.md`, and `docs/tree.md` updated with author, repository, and license metadata.

## Added

- **Service tests** (`tests/services/`) covering the aggregate-row filter, partner deduplication, and EBOPS lookup corrections.
