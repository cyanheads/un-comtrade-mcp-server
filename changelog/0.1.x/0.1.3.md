# 0.1.3 — 2026-05-26

- **`.github/FUNDING.yml`** — GitHub Sponsors and Buy Me a Coffee links.
- **`manifest.json`** added to `package.json` `files` array so it ships with the npm package.
- **Install badges** (Claude Desktop `.mcpb`, Cursor deeplink, VS Code deeplink) added to README header.

- **Docker image** built (linux/amd64 + linux/arm64) and pushed to `ghcr.io/cyanheads/un-comtrade-mcp-server:0.1.3`.
