# 0.1.0 — 2026-05-25

Initial release of `un-comtrade-mcp-server`.

## Added

- `comtrade_lookup_countries` — resolve country and area names to Comtrade M49 numeric codes; accepts partial names, ISO alpha-2/alpha-3; `role` filter for reporter vs. partner distinction; `validAsReporter` flag on results
- `comtrade_search_commodities` — keyword and code-prefix search across the HS commodity hierarchy; 2-, 4-, and 6-digit aggregation levels; `recommended_query_code` field for downstream query construction
- `comtrade_list_service_categories` — browse and search EBOPS 2010 service trade categories; keyword filter and parent-code traversal
- `comtrade_get_trade_flows` — bilateral trade flow records from `data/v1/get` (authenticated) or `public/v1/preview` (no key); multi-period array input; `truncated` flag when the 500-record free-tier cap is hit
- `comtrade_get_trade_balance` — parallel export + import fetch, local balance computation; returns signed balance, component values, and coverage ratio
- `comtrade_get_top_partners` — rank trading partners by value for a reporter/commodity/flow/period; local sort over disaggregated API response
- `comtrade_get_top_commodities` — rank HS chapters or headings by value; symmetric counterpart to `comtrade_get_top_partners`
- `comtrade_get_services_trade` — bilateral services trade data (EBOPS 2010); same structure as goods flow tool
- `comtrade_get_data_availability` — check published dataset coverage by reporter/period/classification before constructing expensive queries
- `comtrade://countries` resource — complete reporter and partner area code list loaded from UN reference files at startup
- `comtrade://hs-classification/{level}` resource — top-level HS hierarchy at level `2`, `4`, or `6`
- `ComtradeReferenceService` — fetches and indexes reporter/partner lists, HS hierarchy, and EBOPS categories at startup; serves all lookup tools from in-memory cache
- `ComtradeDataService` — authenticated/preview request builder with exponential backoff on 429, configurable timeout, and key-fallback logic
- `ComtradeMetaService` — wraps data availability and metadata endpoints
