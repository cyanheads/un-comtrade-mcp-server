# 0.1.1 — 2026-05-25

## Fixed

- **`ComtradeReferenceService.fetchJson`** — unwraps the `{ results: [...] }` envelope in Comtrade reference responses; without this, all reference data failed to load and the server crashed at startup (issues [#1](https://github.com/cyanheads/un-comtrade-mcp-server/issues/1), [#2](https://github.com/cyanheads/un-comtrade-mcp-server/issues/2), [#3](https://github.com/cyanheads/un-comtrade-mcp-server/issues/3))
- **`isGroup` / `isLeaf` normalization** — accept `boolean | string | number` for both flags; the live API returns booleans where the type declared only `string | number`
- **`comtrade_get_top_commodities` aggrLevel filter** — the preview endpoint returns `aggrLevel: null` for all records; infer level from `cmdCode` length when `aggrLevel` is absent so the filter isn't bypassed
- **Startup log drop** — deferred the reference-data-loaded log via `setImmediate` so it fires after framework initialization completes and the logger is live
