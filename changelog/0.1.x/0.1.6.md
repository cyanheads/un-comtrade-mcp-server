# 0.1.6 — 2026-08-21

## Changed

- **Framework `@cyanheads/mcp-ts-core` `^0.10.6` → `^0.12.3`** — adopts the MCP SDK v2 baseline (`@modelcontextprotocol/server` `^2.0.0`): every endpoint serves protocol revision 2026-07-28 alongside the 2025 era, advertised JSON Schema is 2020-12, and the advertised `outputSchema` declares the error envelope.
- **Tool inputs are strict** — an unrecognized argument key is rejected by name instead of stripped (`additionalProperties: false` on every advertised `inputSchema`). Clients sending extra keys must drop them.
- **Empty-result and truncation notices move to `ctx.enrich`** across all eight tools — `notice` left the declared output schema and rides the enrichment block, which reaches both `structuredContent` and `content[]`. `comtrade_search_commodities` and `comtrade_list_service_categories` also emit a pagination notice when results are capped.
- **Bun 1.4.0** — Dockerfile stages pin `oven/bun:1.4.0(-slim)` with `$BUILDPLATFORM` on the build stage, `packageManager` → `bun@1.4.0`; production installs add `--omit=peer` so optional peer tiers stay out of the runtime image.
- **Supply-chain install guard** — `bunfig.toml` gains a 3-day `minimumReleaseAge` hold (the framework excluded) and the Socket install scanner.
- **Plugin marketplace manifests** — `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and `.codex-plugin/mcp.json` scaffolded and validated by `lint:packaging`.
- **Repo packaging files** — Apache-2.0 `LICENSE`, `.gitattributes` (LF normalization, linguist-generated markers), `.github/SECURITY.md` disclosure policy, `FUNDING.yml` trimmed to active entries.
- **devcheck** — vendored skills and scripts synced from the framework, adding the floating-dependency-specifier gate (`scripts/check-dependency-specifiers.ts`) and plugin-manifest checks.

## Fixed

- **Invalid HS level throws `ValidationError`** — the `comtrade://hs-classification/{level}` resource rejected out-of-range levels with `NotFound`; the code now matches the failure.
- **Request-context correlation** — the reference service logs `filename` via `additionalContext` (SDK v2 removed ad-hoc key spreads), and the subscription-key header reads a narrowed local instead of a non-null assertion.
