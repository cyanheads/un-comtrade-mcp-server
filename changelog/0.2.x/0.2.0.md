# 0.2.0 — 2026-10-13

## Added

- **SITC goods queries** accept `S1`–`S4` and `SS` on flows and balance, with revision-specific descriptions and a notice when references are unavailable. HS search remains HS-only. ([#7](https://github.com/cyanheads/un-comtrade-mcp-server/issues/7))

## Changed

- **Availability dates** replace the unpopulated `publicationDate` output with independent optional `firstReleased` and `lastReleased` timestamps. Consumers referencing the removed property must use the appropriate release date. ([#16](https://github.com/cyanheads/un-comtrade-mcp-server/issues/16))
- **Bounded reads** accept up to 120 periods and 200 commodity codes, serve the first 12/20, and name unserved inputs on both result surfaces. Search/category/ranking limits above their former ceilings return all retrieved matches without increasing upstream work.
- **Distribution and development guidance** document the existing hosted endpoint, subscription-dependent access, Bun 1.4.3 images, and synced framework skills.

## Fixed

- **Commodity rankings** request `AG2`/`AG4`, default to World, and retain distinct commodities. ([#8](https://github.com/cyanheads/un-comtrade-mcp-server/issues/8))
- **Preview coverage** discloses any raw 500-record response before filtering, preserves cap information on empty results, and warns when balances may be incomplete. Counts remain upstream response counts. ([#9](https://github.com/cyanheads/un-comtrade-mcp-server/issues/9))
- **Period arrays** use sequential paced preview requests, retain each period, coordinate concurrent flows and retries, and propagate cancellation or upstream failure. Balance requires two preview requests per period. ([#13](https://github.com/cyanheads/un-comtrade-mcp-server/issues/13))
- **Availability defaults** resolve omitted or blank classifications to `HS` for goods and `EB10` for services. ([#11](https://github.com/cyanheads/un-comtrade-mcp-server/issues/11))
- **Goods totals** treat omitted or empty commodity arrays as `TOTAL`. ([#17](https://github.com/cyanheads/un-comtrade-mcp-server/issues/17))
- **Authenticated guidance** removes unsupported numeric retrieval promises; limits depend on UN Comtrade and the subscription. ([#18](https://github.com/cyanheads/un-comtrade-mcp-server/issues/18))
