# 0.5.1 — 2026-11-28

## Added

- **BEC revisions B4 and B5** are available in commodity search, goods flows, and trade balance. Search uses each revision's native levels and labels. ([#75](https://github.com/cyanheads/un-comtrade-mcp-server/issues/75))
- **`isOriginalClassification`** identifies original and converted classifications on goods rows and availability records when UN Comtrade supplies the flag. ([#79](https://github.com/cyanheads/un-comtrade-mcp-server/issues/79))

## Changed

- **Batch queries** accept up to 1,000 raw entries per period, commodity, or reporter array and report distinct unserved values. Set `COMTRADE_CLAMP_LIMITS=false` to retain the prior raw ceilings of 120 periods and 200 codes or reporters. ([#80](https://github.com/cyanheads/un-comtrade-mcp-server/issues/80))
- **Trade values** use decimal arithmetic for totals and differences, with locale-independent formatting that preserves the returned precision. ([#81](https://github.com/cyanheads/un-comtrade-mcp-server/issues/81))

## Fixed

- **Trade balance** omits the balance and coverage ratio for capped or incomplete flows while retaining known sums. Interpret BEC balances using the available row provenance. ([#69](https://github.com/cyanheads/un-comtrade-mcp-server/issues/69))
- **Services availability** defaults to as-reported EB, matching services trade retrieval. ([#70](https://github.com/cyanheads/un-comtrade-mcp-server/issues/70))
- **Goods valuation** documents the import CIF-to-FOB fallback and points to row-level valuation fields for mirror comparisons. ([#72](https://github.com/cyanheads/un-comtrade-mcp-server/issues/72))
- **Scoped commodity rankings** return errors when the initial parent lookup or required HS catalog load fails. Successful empty lookups and partial descendant retrievals retain their coverage reporting. ([#73](https://github.com/cyanheads/un-comtrade-mcp-server/issues/73))
- **Goods partner rankings** list partners with unknown values separately and disclose the coverage of ranks, totals, and shares on both response surfaces. ([#74](https://github.com/cyanheads/un-comtrade-mcp-server/issues/74))
