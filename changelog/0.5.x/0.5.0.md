# 0.5.0 — 2026-11-21

## Added

- **`comtrade_get_top_services_partners`** ranks export destinations or import sources for a reporter, year, and service category, with shares based on eligible partner values and coverage reported for incomplete series. ([#65](https://github.com/cyanheads/un-comtrade-mcp-server/issues/65))

## Changed

- **`comtrade_get_trade_flows` and `comtrade_get_services_trade`** return 25 records by default in a stable order. Follow `nextOffset` with the same filters. Pages cap at 1,000 records, and `COMTRADE_CLAMP_LIMITS=false` rejects larger limits. ([#64](https://github.com/cyanheads/un-comtrade-mcp-server/issues/64))
- **`comtrade_get_data_availability`** lists the newest periods first within each reporter. Start at offset zero to browse the new order. ([#67](https://github.com/cyanheads/un-comtrade-mcp-server/issues/67))
- **`comtrade_list_service_categories`** matches descriptions containing every query term in any order after code and phrase matches. ([#66](https://github.com/cyanheads/un-comtrade-mcp-server/issues/66))

## Fixed

- **`comtrade_get_top_commodities`** reports complete empty coverage when a scoped request succeeds with no upstream records. ([#61](https://github.com/cyanheads/un-comtrade-mcp-server/issues/61))
- **`comtrade://hs-classification/{level}`** identifies which H0–H6 catalogs list each code, including historical codes, and names unavailable catalogs when membership cannot be provided. ([#62](https://github.com/cyanheads/un-comtrade-mcp-server/issues/62))
- **`comtrade_lookup_countries`** names areas excluded by the requested role and shows how to look them up across roles. ([#63](https://github.com/cyanheads/un-comtrade-mcp-server/issues/63))
- **Goods breakdowns** omit placeholder unit pairs for missing quantities and choose a stable representative when the largest partner rows tie. ([#64](https://github.com/cyanheads/un-comtrade-mcp-server/issues/64))
