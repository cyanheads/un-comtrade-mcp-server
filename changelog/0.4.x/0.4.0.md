# 0.4.0 — 2026-11-13

## Added

- Add `comtrade_get_top_reporters` to rank reporting areas by goods trade value. (#57) Shares use the retrieved set and ranks are withheld when coverage or values are unresolved.
- Add HS chapter and heading drill-downs to `comtrade_get_top_commodities`, including level-6 subheadings. (#56) Shares use the reported parent value when available.

## Changed

- Show edition membership and historical parent descriptions in default HS search results. (#54) Use the reported edition to look up the code's meaning.
- Match HS and SITC search descriptions containing every query term in any order, after contiguous matches. (#55)
- Match `St` and `St.` within country names and normalize apostrophe variants. (#59)

## Fixed

- Use 490 for Taiwan goods and 158 for Taiwan services partner queries. (#50)
- Reject `AG<n>` selectors in `comtrade_get_top_partners`. (#51)
- Warn when goods or services partner breakdowns include the overlapping World total. (#52)
- List requested goods selectors without records in completed, uncapped trade flows and balances. (#53)
- Report past-the-end availability offsets in both response formats and give classification-specific validation errors. (#58)

## Dependencies

- `@biomejs/biome` ^2.6.6 → ^2.6.7
